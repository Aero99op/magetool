# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues or credential leakage concerns privately by emailing the maintainer directly or opening a private GitHub Security Advisory. 

We take vulnerabilities seriously and aim to address confirmed security defects within 48 hours.
